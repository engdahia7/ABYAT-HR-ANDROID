# أبيات للموظفين — Android v1.1

الرابط داخل التطبيق:
`https://abyategy.gt.tc/hr/`

## المزايا المضافة
- اسم التطبيق: **أبيات للموظفين**.
- هوية عنابية وواجهة إطلاق بيضاء مستوحاة من الشعار المرسل.
- شاشة بداية Native Splash Screen.
- حفظ جلسة الدخول.
- حماية الجلسة الموجودة ببصمة الجهاز أو قفل الجهاز عند إعادة فتح التطبيق.
- جسر Native للبصمة يمكن للويب استدعاؤه بـ `ABYATHR.requestBiometric()`.
- قناة إشعارات Android أصلية.
- جسر إشعارات للويب: `ABYATHR.showNotification('العنوان','النص')`.
- صلاحيات الإشعارات على Android 13+.
- GPS للبصمة/الحضور.
- رفع وتنزيل الملفات.
- سحب للتحديث وروابط خارجية آمنة.

## ملاحظة مهمة عن الإشعارات
الإشعارات المحلية/القادمة من الصفحة أثناء تشغيل التطبيق جاهزة. الإشعارات Push عندما يكون التطبيق مغلقًا تحتاج Firebase Cloud Messaging ومفتاح/إعدادات الخادم، لذلك لا يتم الادعاء بأنها مفعلة دون إعداد Firebase.

## إخراج APK
افتح المجلد في Android Studio، ثم:
`Build > Build App Bundles or APKs > Build APKs`

المشروع يستخدم:
- JDK 17+
- compileSdk 35
- Android Gradle Plugin 8.7.3
- Gradle 8.9

## ملاحظة الشعار
الصورة التي أرسلتها في المحادثة استُخدمت كمرجع بصري للهوية. للحصول على تطابق بكسل-ببكسل للأيقونة مع ملف الشعار الأصلي، استبدل الـvector الحالي بملف PNG/SVG الأصلي عالي الدقة.
